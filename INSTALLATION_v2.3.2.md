# Installation

1. Décompresse le ZIP.
2. Copie tout dans `footballbrain-api`.
3. Accepte le remplacement des fichiers.
4. Ne touche pas à `.env`.
5. Exécute :

```bash
npm run check
git add .
git commit -m "Fix true FootballBrain explainability"
git push
```

Après Railway, recharge Base44 avec `Ctrl + F5`. Le frontend n'a pas besoin d'être modifié.
